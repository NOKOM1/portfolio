# Портфолио Дениса

https://nokom1.github.io/portfolio/

Структура: представление → галерея демо → Telegram-контакт. Единый шрифт Golos Text. Галерея перелистывается свайпом, кнопками или клавишами. Фон с волнистыми линиями можно остановить; системный reduced-motion имеет приоритет. Демо подписаны, готовый Telegram-бот не заявляется.

Статический HTML/CSS/JS без сборки. Для Pages: main, /(root), .nojekyll. Галерея и фон адаптированы по предоставленным пользователем TiltedGridHero и Waves.

## Текущая версия

Центрированная композиция; нижняя панель быстрых переходов. В центре панели — переключение между вишнёвой и светлой темой (белый/розовый/вишнёвые акценты). Выбор хранится локально. Галерея листается нативно; при дальнейшем вертикальном скролле обложки расходятся, при взаимодействии возвращаются для просмотра. Тихий режим и системный reduced-motion отключают движение. Активные модули: gallery.js, scatter.js, dock.js, waves.js.

Анимация галереи: сначала рамка и пауза для просмотра, затем боковые карточки уходят в стороны, выбранная — вверх. Ручное листание сбрасывает разлёт.
